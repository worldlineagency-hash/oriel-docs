Content for each product

The nutrition table, ingredient spotlight, product FAQ and similar sections hold content that's different for every product. There are two ways to set it up.

Option 1: a template per product#

Best for stores with a handful of products.

  1. In the theme editor, open a product page and choose Create template from the template menu at the top. Base it on featured (or powder) and name it after the product.
  2. Fill in the sections for that product: nutrients, claims, ingredients, FAQ.
  3. In Shopify admin, open the product and choose the new template under Theme template.

Option 2: dynamic sources (metafields)#

Best for larger catalogues: one template shows each product's own content.

  1. In Settings > Custom data > Products, add metafield definitions, for example Serving size (single line text) or Benefits (list of single line text).
  2. Fill them in on each product.
  3. In the theme editor, select a setting (for example the nutrition table's Serving size or a Collapsible row's Content) and click the Connect dynamic source icon next to it. Pick the metafield.

Blocks are fixed per template, so for a table with a different number of rows per product, use option 1 or a rich text metafield in a Collapsible row.

Nutrition table#

  • Heading: [product] is replaced by the product title. Outside a product page it's replaced by Name outside a product page.
  • Serving size, a round image, column titles and a Note under the table.
  • Nutrient blocks: name, amount and reference value in %. Values over 100% show a full bar; leave it empty to show a dash.
  • Claim blocks: short checked lines beside the table.

Only use health claims that are authorised where you sell. In the EU and UK, use the exact wording of the authorised claim, and only when the product contains enough of the nutrient.

Ingredient spotlight#

A large image of the first ingredient with Ingredient blocks (image, name, text) and Fact blocks (label and value, for example Serving: 1 capsule). Set the link to #Science to jump to the nutrition table.

Product FAQ#

The FAQ section takes one Row block per question. Avoid questions that invite health promises, such as when results appear.

Image comparison#

Before and after images with a slider, and steps beside them. Use two images with the same size and framing.
