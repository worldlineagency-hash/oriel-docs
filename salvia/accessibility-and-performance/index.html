Accessibility and performance

Accessibility#

  • Everything works with a keyboard, with a visible focus outline and a skip link to the content.
  • Menus, the cart drawer, quick view and popups keep focus inside while open and return it when closed.
  • Changes such as adding to the cart are announced to screen readers.
  • Slideshows, announcements and videos can be paused, and don't move for visitors who prefer reduced motion.
  • Default color schemes meet WCAG AA contrast. Check contrast when you change colors.
  • Add alt text to your images in Shopify admin; decorative images are hidden from screen readers.

Performance#

  • No frameworks: small scripts that load only for the sections on the page.
  • Responsive images in the right size for each screen; images below the first screen load lazily.
  • Videos and maps load only when they're needed.

Apps add their own code. If your store slows down, check which apps load on the page.
