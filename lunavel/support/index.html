Support

We help with questions about Lunavel's features and settings, and we fix bugs in the theme. We reply within two business days.

Before you write#

  • Check the FAQ and the page of this guide about the feature you're using.
  • If the problem started after you installed an app or edited code, try the same page in a fresh copy of Lunavel from the Theme Store. If it works there, the app or the code change is the likely cause.

What support includes#

  • Help with the theme's settings, sections and features.
  • Fixes for bugs in the theme.

Support doesn't include custom design or code changes, problems caused by third-party apps or edited theme code, or setting up your store's products and content. For these, we recommend a Shopify Partner.
